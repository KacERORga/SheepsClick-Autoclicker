# 🐑 Sheeps`Click- Auto Clicker 100 CPS

**Мощный, легкий и настраиваемый автокликер для Minecraft.**  
*Разработано с любовью студией **KWCHERga_STUDIOS** (проект Sheeps.net).*

---

## 📖 Описание
**Sheeps`Click- Auto Clicker 100 CPS** — это качественный клиентский мод для Minecraft, который позволяет автоматизировать клики мыши. Идеально подходит для фарма, строительства, рыбалки или сражений в одиночной игре и на приватных серверах. 

Мод оптимизирован, не нагружает систему и поддерживает гибкую настройку скорости кликов вплоть до **100 CPS** (кликов в секунду).

## ✨ Основные возможности
* 🚀 **Скорость до 100 CPS:** Достигайте максимальной скорости кликов без лагов и зависаний игры.
* ⚙️ **Гибкая настройка:** Меняйте скорость (CPS), задержку и режимы работы прямо в меню мода.
* ⌨️ **Удобные хоткеи:** Включение/выключение автокликера одной кнопкой.
* 🛡️ **Режим "Умный клик":** (Опционально) Отключение автокликера, если в руке нет нужного предмета.
* 🎨 **Чистый UI:** Минималистичное меню настроек, которое не мешает игровому процессу.

## 📥 Установка
1. Установите загрузчик модов: **Forge** или **Fabric** (выберите подходящую версию для вашего Minecraft).
2. Скачайте последнюю версию мода `Sheeps`Click- Auto Clicker 100 CPS` (.jar).
3. Откройте папку с игрой (в лаунжере нажмите "Открыть папку с игрой").
4. Переместите скачанный `.jar` файл в папку `mods`. *(Если папки нет, создайте её).*
5. Запустите игру и наслаждайтесь!

## 🎮 Управление
* **Вкл/Выкл автокликер:** `[Ваша настроенная клавиша, например, R]`
* **Открыть меню настроек:** `[Ваша клавиша, например, O]`
* *Клавиши можно переназначить в стандартных настройках управления Minecraft -> "Sheeps`Click".*
